# Tazkiyane patch — Productivity tab and installed-app discovery

## Navigation
- Replaced the middle **Activity** bottom-navigation destination with **Productivity**.
- The middle tab now opens the existing Productivity screen directly.
- Removed the old Activity destination screen and its route.
- Removed the Productivity entry from Settings because it is now available directly from the bottom navigation.
- Kept the Home screen Create floating action button for creating habits and tasks.
- Kept task activity-history records and task detail history; only the separate Activity destination was removed.

## Automatic app-usage picker
- Changed the Android MethodChannel bridge from launcher-intent-only discovery to installed-application discovery.
- Added `QUERY_ALL_PACKAGES` to the Android manifest generated by `tool/prepare_android.sh`.
- Includes normal installed apps and user-visible system apps with launcher entries, while omitting non-launchable Android system services and Tazkiyane itself.
- The picker continues to show app names and search/selection checkboxes; selected package names remain the identifiers used by UsageStats tracking.

## Android distribution note
`QUERY_ALL_PACKAGES` is a broad package-visibility permission. It is appropriate for this private/sideloaded build where the installed-app picker is a core feature. Google Play distribution is subject to Google Play's package-visibility policy and approval requirements.

## Version
- Bumped the app version to `0.6.1+24` so the updated APK can be installed over the previous `0.6.0+23` build without removing local data.

## Verification
The project source and CI scaffold script were updated. This environment does not have the Flutter SDK or Android SDK, so a local Flutter analyze/test/APK build could not be run here. GitHub Actions should be used to verify the build on the next push.
